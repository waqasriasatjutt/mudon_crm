Bring the complete Odoo 19 Enterprise visual experience to your Community edition — free of subscription.

About This Module

Enterprise look & feel for Odoo 19 Community — no subscription required.

🏠
Full-Page Home Menu

Animated app grid with purple-teal gradient background and keyboard navigation — identical to Odoo 19 Enterprise.

☰
White Enterprise Navbar

Replaces Community's purple header with the clean white navbar, dark text, and 1px shadow — pixel-perfect match with Enterprise.

🎨
Purple & Teal Brand Colors

Enterprise's #714B67 purple and #017e84 teal applied across all UI components — buttons, links, active states.

▶
Smooth App Animations

App icons lift on hover with shadow transitions and translateY effect — the exact same animation Enterprise uses.

⚙
Bootstrap Overrides

Applies Enterprise's Bootstrap variable overrides — shadows enabled, border-radius resets, teal focus highlights on form inputs.

📱
Mobile Responsive

Home menu adapts to small screens. Navbar uses Bootstrap responsive utilities for tablets and phones.

⌨
Keyboard Navigation

Navigate home menu with arrow keys, open apps with Enter, and trigger the menu toggle with the H accesskey.

🔒
web_responsive Compatible

No dependency on web_responsive. Works alongside all standard Community apps and OCA modules.
